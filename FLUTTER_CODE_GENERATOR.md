# Flutter Code Generator

M3E Canvas can generate a runnable Flutter project from the current design.

1. Start the web app with `npm install` and `npm run dev` (Node.js 22.12+).
2. Open the **AI** tab and choose a provider, model, base URL, and API key.
3. Open the Prompt tab and select **Flutter** as the target.
4. Choose **Generate Flutter ZIP**. When generation finishes, choose **Download ZIP**.
5. Extract the ZIP, open that folder in a terminal, and run:

   ```bash
   flutter create .
   flutter pub get
   flutter run
   ```

The browser sends the design prompt and your API key directly to the AI provider configured in the AI tab. The project is generated by that provider; review the Dart code before using it. API usage may incur provider charges. Do not share your API key or the generated ZIP publicly if it contains private information.
